# Pocket - Smart Financial Management

**Complete User & Developer Guide**

---

## 📱 What is Pocket?

Pocket is a modern, privacy-first financial management Progressive Web App (PWA) that helps you track expenses, manage budgets, set financial goals, and gain insights into your spending patterns.

### Key Features
- ✅ **Manual Expense Tracking** - Full control over your data
- ✅ **Budget Management** - Set and track budgets by category
- ✅ **Financial Goals** - Set savings goals and track progress
- ✅ **Reports & Analytics** - Comprehensive financial reports
- ✅ **Recurring Transactions** - Manage subscriptions and bills
- ✅ **Savings Accounts** - Track multiple savings accounts
- ✅ **Multi-Currency Support** - Track expenses in any currency
- ✅ **Quick Expense Entry** - Fast mobile-optimized entry
- ✅ **PWA Ready** - Install on any device, works offline
- ✅ **Privacy First** - No bank syncing, your data stays yours

## 🚀 Getting Started

### For Users

#### Installing the App (PWA)

**Desktop (Chrome/Edge):**
1. Visit the app in your browser
2. Look for the install icon in the address bar or the install prompt
3. Click "Install" to add to your desktop

**Mobile (Android Chrome):**
1. Visit the app in Chrome
2. Tap the menu (three dots) → "Add to Home Screen"
3. Or use the install prompt that appears

**iOS (Safari):**
1. Visit the app in Safari
2. Tap the Share button
3. Select "Add to Home Screen"
4. The app will appear on your home screen

#### First Steps
1. **Create an Account** - Sign up with email or Google
2. **Set Your Currency** - Choose your default currency
3. **Add Your First Transaction** - Start tracking expenses
4. **Set Up Budgets** - Create budgets for your spending categories
5. **Set Financial Goals** - Define savings targets

## 📊 Features Overview

### 1. Transaction Management

#### Adding Transactions
- **Quick Entry**: Use the floating action button (FAB) for fast expense entry
- **Full Entry**: Use the "Add Transaction" dialog for detailed entries
- **Quick Flow Mode**: Category → Item → Price for rapid entry

#### Editing Transactions
- Click the edit icon (pencil) on any transaction
- Update amount, description, category, date, or notes
- Changes are saved immediately

#### Transaction Notes
- Add optional notes to any transaction
- Useful for tax preparation and context
- Notes are searchable

#### Filtering & Search
- **Search**: Find transactions by description, category, or notes
- **Date Filters**: Today, This Week, This Month, Last Month, This Year, Custom Range
- **Category Filter**: Filter by specific categories
- **Type Filter**: Show only income or expenses
- **Sort Options**: Sort by date, amount, description, or category

#### Export Data
- **CSV Export**: Export all or filtered transactions to CSV
- **PDF Reports**: Generate comprehensive PDF reports from the Reports page

---

### 2. Budget Management

#### Creating Budgets
1. Go to the Budgets section on the dashboard
2. Click "Create Budget"
3. Select category, amount, and period (monthly/weekly/yearly)
4. Set alert threshold (optional)
5. Save

#### Budget Tracking
- Visual progress bars show spending vs budget
- Color coding: Green (under budget), Yellow (approaching limit), Red (over budget)
- Remaining amount displayed
- Budget alerts when approaching limits

#### Managing Budgets
- Edit budgets anytime
- Activate/deactivate budgets
- Delete budgets you no longer need

---

### 3. Financial Goals

#### Setting Goals
1. Go to the Goals section
2. Click "Create Goal"
3. Enter goal name, target amount, and optional deadline
4. Associate with a category (optional)
5. Save

#### Tracking Progress
- Visual progress indicators
- Current amount vs target amount
- Percentage complete
- Time remaining (if deadline set)

#### Managing Goals
- Update current amount as you save
- Edit or delete goals
- Mark goals as active/inactive

---

### 4. Reports & Analytics

#### Accessing Reports
- Navigate to "Reports & Analytics" from the dashboard
- Or use the back button to return to dashboard

#### Report Types
- **This Year**: Full year overview
- **This Month**: Current month analysis
- **Custom Range**: Select your own date range

#### Report Contents
- **Summary Metrics**: Total Income, Total Expenses, Net Balance, Savings Rate
- **Spending Charts**: Time series visualization of spending
- **Category Breakdown**: Spending by category with percentages
- **Monthly Trends**: Income vs expenses by month

#### Exporting Reports
- **PDF Export**: Generate professional PDF reports
- **CSV Export**: Export transaction data for analysis

### 5. Recurring Transactions

1. Go to Recurring Transactions section

3. Enter transaction details
4. Set frequency (monthly, weekly, yearly)
5. Set next occurrence date

#### Managing Recurring Transactions
- View all recurring transactions in one place
- Edit or delete recurring transactions

- See next occurrence date

## 🔧 Troubleshooting

### App Not Installing?
- **Check Browser**: Use Chrome, Edge, or Safari (iOS 16.4+)
- **Check HTTPS**: App must be served over HTTPS (or localhost)
- **Clear Cache**: Try clearing browser cache and cookies
- **Check Console**: Look for errors in browser developer console

### Icons Not Updating?
- **Clear Browser Cache**: Clear Safari/Chrome cache
- **Uninstall & Reinstall**: Remove app and reinstall
- **Wait 24-48 Hours**: iOS Safari caches icons aggressively

### Date Input Not Opening Calendar?
- The entire date input field should be clickable
- If not working, try clicking directly on the calendar icon
- Check browser compatibility (works in all modern browsers)

### Export Not Working?
- **PDF Export**: Requires JavaScript to be enabled
- **CSV Export**: Check browser download settings
- **Large Files**: May take a moment for large datasets
